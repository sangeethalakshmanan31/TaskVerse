TaskVerse – Database
📌 Project Overview

TaskVerse is a Project and Task Management System designed to help managers and employees manage companies, projects, teams, tasks, comments, issues, and notifications in one centralized platform.

The database is developed using PostgreSQL and managed through Supabase.

🗄️ Database Technology
Database: PostgreSQL
Database Platform: Supabase
Database Type: Relational Database
Primary Key: UUID
Security: Row Level Security (RLS)
Query Language: SQL
📂 Database Structure

The database contains the following tables:

Users
Companies
Projects
Teams
Team Members
Tasks
Comments
Issues
Notifications
